PROCESSING MODES

從表面刻字，到水晶內的立體作品。

先決定圖案要留在表面，還是出現在材料內部。兩種模式的鏡頭、定位與材料要求不同。

01 / SURFACE

玻璃表面雕刻

圖案留在物件表面，適合酒杯、玻璃獎座、香氛瓶或品牌標記。曲面件要確認固定方式、對焦與可加工範圍。

02 / INNER

2D／3D 水晶內雕

圖案由水晶內部的點組成，保留外部表面。可用照片製作平面內雕，也可用 3D 模型呈現立體效果。

03 / FINE DETAIL

細節標記與浮雕

可依材質評估細字、圖紋、表面浮雕及特定材料切割。金屬可評估表面標記，深雕與金屬切割請比較 MOPA 機型。

FROM FILE TO FINISH

兩種工作流程，先看清楚差別。

CRYSTAL WORKFLOW

用照片或模型做水晶內雕

  1. 準備適合內雕的 K9 光學水晶，量測長、寬、高。
  2. 依原廠指引更換內雕鏡頭、安裝對應升降台並固定工件。
  3. 在 xTool Studio 選擇內雕模式，匯入照片或模型，設定工件尺寸與圖案位置。
  4. 預覽並確認圖案完全落在有效範圍內，依原廠安全流程先做樣品。

SURFACE WORKFLOW

先確認定位，再開始加工

表面加工可利用相機預覽與輔助定位，適合把圖案對準既有物件。透明、鏡面或高反光材料可能需要手動對焦。批次製作前，先用同批材料測試效果，再規劃治具、排版與進料方式。

MATERIAL GUIDE

先看材質，再決定怎麼刻。

同一種材料可能適合表面雕刻，卻不適合內雕或切割。建議先用實際材料試作。

材料可評估的用途選材與加工重點
K9 光學水晶2D／3D 內雕確認材質、工件尺寸與內雕有效體積。一般透明玻璃不能直接當作內雕水晶。
玻璃表面刻字、圖案依玻璃種類、厚度與形狀測試。玻璃切割只評估原廠列出的適用玻璃與條件。
壓克力表面雕刻、部分板材切割不支援壓克力內雕；全透明壓克力不列入此機型的原廠切割範圍。
金屬細字、標誌、表面標記效果依合金與表面處理而異。需要深雕、金屬浮雕或切割時，優先評估 MOPA。
木、紙、皮革、陶瓷依材料做表面加工確認材料成分與塗層；切割能力依厚度與材料而異。
塑膠、矽膠部分材質可做細節標記先辨識成分並核對原廠安全指引。不加工成分不明的材料或含氯材料。

FAQ

常見問題

內雕和表雕可以用同一顆鏡頭嗎？

兩種模式使用對應的鏡頭。切換內雕時，請依 xTool Studio 與原廠指南更換鏡頭、安裝升降台並確認材料尺寸。

一張照片可以直接做成 3D 水晶嗎？

照片可以做成 2D 內雕；若要呈現有立體深度的作品，需要先準備對應的 3D 內容。可提供照片或模型，洽詢可達成的效果。

一般玻璃、透明壓克力都能做內雕嗎？

原廠建議使用適用的 K9 光學水晶；一般透明玻璃不一定適合。這款不支援壓克力內雕。

水晶球也可以刻嗎？

可以評估，但曲面會改變光線路徑，需依原廠流程使用對應治具或其他處理方式。第一次做內雕，可從平面的水晶方塊開始。

適合做金屬深雕或切割嗎？

這款以精細表面加工與玻璃應用為主。若常做金屬深雕、浮雕或切割，建議比較 F2 Ultra 的 MOPA 光源。

詢價時要準備什麼？

告訴我們工件材質、尺寸、照片或圖稿、預計數量，以及想做表面雕刻還是水晶內雕。若是杯瓶或長件，也請提供外形與尺寸。

有想刻的樣品？

把材料、尺寸與圖稿告訴我們，一起確認加工方式、配件與報價。
