MATRIX ROBOTICS / LEARN BY BUILDING
BUILD. CODE. DISCOVER.

不是只讓機器人動。
是讓思考開始動。

MATRIX 的模組化結構、控制器與感測配件，讓學習從「照著做」走向「想辦法做到」。依程度與目標，選擇合適的套件與延伸方向。

01
組裝，理解結構

從機構與零件搭配開始，觀察結構如何影響機器人的行動。

02
編程，串起邏輯

透過圖形化程式與 Arduino 相關工具，練習控制、感測與除錯。

03
挑戰，把知識用出來

以循線、任務與專題為方向，結合測試、調整與團隊合作。
